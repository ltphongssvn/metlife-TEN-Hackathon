# MetLife TEN Hackathon - AI Focus Assistant

## Project Overview
An intelligent web application using AI and machine learning to help immigrants maintain focus on education despite financial and cultural pressures in the USA.

## Features
- AI-powered consultation and encouragement
- RAG-based knowledge system
- Multi-agent architecture
- Voice-enabled conversational AI using Google Cloud

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js/Express
- **AI/ML:** Dialogflow, Google Cloud AI
- **Cloud:** Google Cloud Platform
- **Architecture:** Multi-agent RAG system

## Project Structure
```
metlife-TEN-Hackathon/
├── frontend/          # React application
├── backend/           # Node.js API server
├── agents/            # Multi-agent system
├── docs/              # Documentation
└── infrastructure/    # Cloud deployment configs
```
